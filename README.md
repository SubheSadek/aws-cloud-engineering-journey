# AWS Cloud Engineering Journey

A structured, hands-on journey toward professional AWS Cloud Engineering, DevOps and Solutions Architecture.

This repository documents my learning, practical experiments, infrastructure implementations and architecture decisions while developing expertise in Amazon Web Services (AWS).

## About This Repository

I am a Fullstack Engineer with experience building and maintaining production applications, managing Linux servers, configuring Nginx, MySQL, Redis, Docker and deploying applications on DigitalOcean.

My objective is to expand this experience into professional cloud engineering by learning how to design, deploy, secure, automate, monitor and scale infrastructure using AWS.

This is not just a collection of tutorials. It is a practical engineering portfolio containing implementation details, architecture diagrams, infrastructure code, technical documentation and lessons learned.

## Learning Objectives

- Understand AWS infrastructure and core cloud services.
- Design secure and scalable cloud architectures.
- Build and manage VPC networking and infrastructure.
- Deploy applications using EC2, ECS and serverless services.
- Manage databases, storage, backups and caching.
- Automate infrastructure using Terraform.
- Implement CI/CD pipelines and deployment strategies.
- Understand high availability, disaster recovery and cost optimization.
- Develop enterprise-level cloud architecture skills.
