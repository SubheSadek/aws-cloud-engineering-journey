# AWS Cloud Engineering Roadmap

A structured 9-month learning plan covering AWS fundamentals, cloud infrastructure, networking, security, DevOps and enterprise architecture.

**Duration:** 9 Months (39 Weeks)  
**Daily Commitment:** 2 Hours  
**Learning Approach:** Theory + Hands-on Labs + Projects  
**Primary Goal:** Professional AWS Cloud Engineer / Solutions Architect

---

## Phase 01 — AWS Fundamentals

**Duration:** Weeks 1–4

### Topics
- AWS Global Infrastructure
- Regions and Availability Zones
- AWS Account Management
- IAM Users, Roles and Policies
- EC2 Instances
- EBS Volumes and AMIs
- S3 Storage
- Route 53
- CloudWatch
- AWS CLI
- Systems Manager

### Practical Assignments
- Configure AWS account security and MFA.
- Create an IAM administrative identity.
- Launch an Ubuntu EC2 instance.
- Configure Nginx and PHP.
- Deploy a Laravel application.
- Configure CloudWatch monitoring.

### Expected Outcome
Understand AWS infrastructure and deploy a basic application using AWS services.

## Final Learning Objectives

By the end of this roadmap, I aim to be able to:

1. Design AWS infrastructure from scratch.
2. Build secure VPC and networking architectures.
3. Deploy and scale production applications.
4. Automate infrastructure using Terraform.
5. Build CI/CD pipelines.
6. Implement monitoring and incident response.
7. Design high-availability and disaster recovery systems.
8. Optimize cloud infrastructure performance and cost.
9. Explain architectural decisions and trade-offs.
